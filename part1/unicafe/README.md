# Unicafe

Like most companies, the student restaurant of the University of Helsinki Unicafe collects feedback from its customers. 

This is a web application to collect customer feedback. There are only three options for feedback: *good*, *neutral* and *bad*.

The application will display the total number of collected feedback for each category, and shows more statistics about the gathered feedback: the total number of collected feedback, the average score (the feedback values are: good 1, neutral 0, bad -1) and the percentage of positive feedback in table form.
